= Aggregate text
:description: How to generate text and structured outputs as aggregations over grouped rows.

This page explains how to generate AI-assisted outputs using aggregation in Cypher.
You can produce a single result per group using the `ai.text.aggregateCompletion()` and `ai.text.aggregateStructuredCompletion()` functions.

[NOTE]
Use `CALL ai.text.completion.providers()` (see xref:reference/functions-procedures.adoc#ai-text-completion-providers[reference]) to see supported providers and their configuration options.

[[aggregate-completion]]
== Aggregate Completion

[cols="1,1,1,3"]
.Signature for `ai.text.aggregateCompletion`
|===
|    *Syntax*        3+| `ai.text.aggregateCompletion(value, prompt, provider, configuration = {}) :: STRING`
|    *Description*   3+| Aggregating function that generates text from the specified prompt across grouped rows.
.5+| *Input arguments* | *Name*          | *Type*   | *Description*
|                        `value`         | `STRING` | The value to aggregate over.
|                        `prompt`        | `STRING` | The prompt to generate text from.
|                        `provider`      | `STRING` | The identifier of the provider: 'Azure-OpenAI', 'Bedrock', 'Bedrock-Nova', 'Bedrock-Titan', 'OpenAI', 'VertexAI'.
|                        `configuration` | `MAP`    | Provider specific configuration, use `CALL ai.text.structuredCompletion.providers()` to find the configuration needed for each provider. You can specify additional vendor options by adding `vendorOptions` with a map of values that will be passed along in the request.
2+| *Returns*                            | `STRING` | Generated text based on the provided prompt.
|===


[.tabbed-example]
====
[.include-with-OpenAI]
======

The example below aggregates product descriptions per product category and asks the external AI provider to summarize the key themes into a short bullet pointed list.

[source, cypher, test-result-skip]
----
MATCH (p:Product)
WITH p, {
    token: $openaiToken,
    model: 'gpt-5-nano'
  } AS config
RETURN p.category AS category,
       ai.text.aggregateCompletion(
         p.description,
         'Summarize the key themes in these product descriptions as a short bullet list.',
         'openai',
         config
       ) AS category_summary
ORDER BY category;
----

[role="queryresult",options="header",cols="1,3"]
|===
| category | category_summary
| "Books" | "- Imaginative storytelling\n- Strong character development\n- Themes of friendship and adventure"
| "Electronics" | "- Battery life and fast charging\n- Camera quality\n- Value for money"
|===

Notes:

- The `value` argument indicates the expression being aggregated. Typically, it is a column varying within the group (for example, `p.description`).
- The `value` argument must be of type `STRING`, use Cypher's toString() function to convert non-string values.
- The function produces a single `STRING` per group.
- Provider identifiers include: `Azure-OpenAI`, `Bedrock`, `Bedrock-Nova`, `Bedrock-Titan`, `OpenAI`, `VertexAI`.


[[aggregate-structured]]
== Aggregate Completion with a structured output
|===
|    *Syntax*        3+| `ai.text.aggregateStructuredCompletion(value, prompt, schema, provider, configuration = {}) :: MAP`
|    *Description*   3+| Aggregating function that generates a structured map based on the specified prompt and JSON schema across grouped rows.
.6+| *Input arguments* | *Name*          | *Type*   | *Description*
|                        `value`         | `STRING` | The value to aggregate over.
|                        `prompt`        | `STRING` | The prompt to generate text from.
|                        `schema`        | `MAP`    | A map describing the JSON schema for the desired output.
|                        `provider`      | `STRING` | The identifier of the provider: 'Azure-OpenAI', 'Bedrock', 'Bedrock-Nova', 'Bedrock-Titan', 'OpenAI', 'VertexAI'.
|                        `configuration` | `MAP`    | Provider specific configuration, use `CALL ai.text.completion.providers()` to find the configuration needed for each provider. You can specify additional vendor options by adding `vendorOptions` with a map of values that will be passed along in the request.
2+| *Returns*                            | `MAP`    | A structured map conforming to the provided schema.
|===

[.tabbed-example]
====
[.include-with-OpenAI]
======

The following example aggregates reviews and asks the external AI provider to extract the common pain points and desired features from them.
It is also asked to return the result as a MAP listing the pain points and requested features, as well as optionally listing the sentiment of the review.

[source, cypher]
----
MATCH (r:Review)
WITH r, {
    token: $openaiToken,
    model: 'gpt-5-nano'
  } AS config
RETURN ai.text.aggregateStructuredCompletion(
         r.comment,
         'From these reviews, extract common pain points and desired features.',
         {
           type: 'object',
           properties: {
             painPoints: { type: 'array', items: { type: 'string' } },
             requestedFeatures: { type: 'array', items: { type: 'string' } },
             sentiment: { type: 'string', enum: ['negative','neutral','positive'] }
           },
           required: ['painPoints','requestedFeatures']
         },
         'openai',
         config
       ) AS review_insights;
----

[role="queryresult",options="header",cols="1"]
|===
| review_insights
| {painPoints: ["slow performance", "confusing menus"], requestedFeatures: ["favorites", "export to CSV"], sentiment: "negative"}
|===

== Tips

- Start with concise prompts and iterate. Aggregations may involve many rows per group; keep prompts efficient.
- Use grouping keys appropriately. Everything not aggregated must be included in the `RETURN` grouping.
