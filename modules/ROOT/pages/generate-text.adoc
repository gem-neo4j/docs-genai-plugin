= Generate text

The function `ai.text.completion` can be used to generate text based on a textual input prompt.
It is similar to submitting a prompt to an LLM.

[role=label--function label--new-2025.11]
[cols="1,1,1,3"]
.Signature for `ai.text.completion`
|===
|    *Syntax*        3+| `ai.text.completion(prompt, provider, configuration) :: STRING`
|    *Description*   3+| Generate text output based on the provided prompt.
.4+| *Inputs* | *Name*          | *Type*   | *Description*
|                        `prompt`        | `STRING` | Textual prompt.
|                        `provider`      | `STRING` | Name of the third party AI provider, see xref:#providers[Providers].
|                        `configuration` | `MAP`    | Provider specific configuration, see xref:#providers[Providers].
| *Returns*          3+| Generated text based on the provided prompt.
|===

== Example

The examples on this page use the link:https://github.com/neo4j-graph-examples/recommendations[Neo4j movie recommendations] dataset, focusing on the `plot` and `title` properties of `Movie` nodes.
There are 9083 `Movie` nodes with a `plot` and `title` property.

image::genai-graph.svg[Example graph connecting person and actor nodes with a movie node via acted in and directed relationships,width=600,role=popup]

To recreate the graph, download and import this link:https://github.com/neo4j-graph-examples/recommendations/raw/main/data/recommendations-5.26.dump[dump file] into an empty Neo4j database.
Dump files can be imported for both link:{neo4j-docs-base-uri}/aura/auradb/importing/import-database/[Aura] and link:{neo4j-docs-base-uri}/operations-manual/current/backup-restore/restore-dump/[self-managed] instances.

[.tabbed-example]
====
[.include-with-OpenAI]
======
The example below selects the 5 top-rated movies, joins their titles and plots into a single, newline-separated string, and asks the external AI provider to pick the most child-friendly one.

[source, cypher, test-result-skip]
----
MATCH (n:Movie) WHERE n.imdbRating IS NOT NULL
ORDER BY n.imdbRating DESC LIMIT 5  // <.>
WITH n.title || ': ' || n.plot AS movie  // <.>
WITH
  reduce(acc = '', item IN collect(movie) | acc || item || '\n') AS movies,  // <.>
  {
    token: $openaiToken,
    model: 'gpt-5-nano',
    vendorOptions: {
      max_output_tokens: 1024,
      instructions: 'Be short.'
    }
  } AS config  // <.>
RETURN ai.text.completion(
    'Here is a list of movies with their titles and plots. Recommend the most child-friendly one.\n\n' || movies,  // <.>
    'openai',
    config
) AS result
----

<.> Pick the 5 top-rated movies.
<.> Join title and plot as `<title>: <plot>`.
<.> Join all movies into a single, newline-separated string.
<.> Provider specific configuration, see xref:#providers-openai[Providers -> OpenAI].
<.> Prompt for the AI model.

[role="queryresult",options="header",cols="1"]
|===

| result
| "Cosmos. It’s an educational, non-graphic science documentary about the universe, making it the most child-friendly option here (parental guidance for younger kids)."

|===

== Chat with context

[role=label--function label--new-2025.12]
[cols="1,1,1,3"]
.Signature for `ai.text.chat`
|===
|    *Syntax*        3+| `ai.text.chat(prompt, chat_id, provider, configuration = {}) :: MAP`
|    *Description*   3+| Chat based on the specified prompt, optionally continuing a previous response.
.5+| *Inputs* | *Name* | *Type* | *Description*
| `prompt` | `STRING` | The user message to send.
| `chat_id` | `STRING` | Previous chat id to continue the conversation. If this is the first message in the conversation, set to null.
| `provider` | `STRING` | The identifier of the provider. See xref:#providers[Providers].
| `configuration` | `MAP` | Provider-specific options. See xref:#providers[Providers].
| *Returns* 3+| `MAP`
|===

[NOTE]
Use `CALL ai.text.chat.providers()` to see supported providers and their configuration options.

[.tabbed-example]
====
[.include-with-OpenAI]
======
.Example — Start a new chat (OpenAI)
[source, cypher, test-result-skip]
----
WITH
  {
    token: $openaiToken,
    model: 'gpt-5-nano',
    vendorOptions: { instructions: 'Be helpful but concise.' }
  } AS conf
RETURN ai.text.chat('Hello! I like space documentaries. Any recommendations?', null, 'openai', conf) AS result
----

<.> Provider specific configuration, see xref:#providers-openai[Providers -> OpenAI].
<.> Set `chat_id` to `null` to start a new conversation.
======

[.include-with-OpenAI-continue]
======
.Example — Continue a chat using a previous chat id (OpenAI)
[source, cypher, test-result-skip]
----
WITH
  {
    token: $openaiToken,
    model: 'gpt-5-nano'
  } AS conf
RETURN ai.text.chat('Could you suggest something more suitable for kids?', $chatId, 'openai', conf) AS result
----

<.> Reuse the chat id from a previous response to continue the conversation. For example, pass it via a parameter `$chatId`.
======

== Run multiple requests in parallel

To run text completion for several prompts in parallel, you have two options:

1. Use link:https://neo4j.com/docs/cypher-manual/current/subqueries/subqueries-in-transactions/#concurrent-transactions[`CALL {...} IN CONCURRENT TRANSACTIONS`], with 1 row per transaction: +
+
[source, cypher]
----
WITH ['Name a movie', 'Name a book'] AS prompts
UNWIND prompts AS prompt
CALL(prompt) {
  WITH
  {
    token: $openaiToken,
    model: 'gpt-5-nano'
  } AS config
  RETURN ai.text.completion(prompt, 'openai', config) AS response
} IN CONCURRENT TRANSACTIONS OF 1 ROW
RETURN response
----
+
2. Use link:https://neo4j.com/docs/cypher-manual/current/planning-and-tuning/runtimes/concepts/#runtimes-parallel-runtime[Cypher's parallel runtime]: label:enteprise-edition[] +
+
[source, cypher]
----
CYPHER runtime=parallel
WITH
  {
    token: $openaiToken,
    model: 'gpt-5-nano'
  } AS config,
  ['Name a movie', 'Name a book'] AS prompts
UNWIND prompts AS prompt
RETURN ai.text.completion(prompt, 'openai', config) AS result
----


[[providers]]
== Providers

You can generate text via the following providers:

- OpenAI (`openai`)
- Azure OpenAI (`azure-openai`)
- Google Vertex AI (`vertexai`)
- Amazon Bedrock Nova Models (`bedrock-nova`)

The query `CALL ai.text.completion.providers()` (see xref:reference/functions-procedures.adoc#ai-text-completion-providers[reference]) shows the list of supported providers in the installed version of the plugin.


[[providers-openai]]
=== OpenAI

.OpenAI parameters
[opts=header, cols="1,1,1,3"]
|===
| *Name*          | *Type*      | *Default* | *Description*
| `model`         | `STRING`    | -         | Model ID (see https://platform.openai.com/docs/models[OpenAI -> Models]).
| `token`         | `STRING`    | -         | OpenAI API key (see https://platform.openai.com/api-keys[OpenAI -> API Keys]).
| `chatHistory`   | `LIST<ANY>` | `[]`      | Optional conversation history to provide context to the model. Pass a list of messages as `MAP` values with the keys `role` and `content` where `role` is either `user` or `assistant` and the content is a `STRING` representing a message.
| `vendorOptions` | `MAP`       | `{}`      | Optional vendor options that will be passed on as-is in the request to OpenAI (see https://platform.openai.com/docs/api-reference/responses/create[OpenAI -> Create a model response]).
|===

.Usage example
[source, cypher]
----
WITH
  {
    token: $openaiToken,
    model: 'gpt-5-nano',
    vendorOptions: {
      max_output_tokens: 1024,
      instructions: 'Be short.'
    },
    chatHistory: [
      {
        role: "user",
        content: "My favorite movies are in the Fantasy or Sci-fi genre."
      },
      {
        role: "assistant",
        content: "Nice! fantasy and sci-fi have great vibes. Want tailored recs?"
      }
    ]
  } AS conf
RETURN ai.text.completion('Yes, please reccomend a movie to me', 'openai', conf) AS result
----

[[providers-vertexai]]
=== Google VertexAI

.VertexAI parameters
[opts=header, cols="1,1,1,3"]
|===
| *Name*          | *Type*      | *Default* | *Description*
| `model`         | `STRING`    | -         | Model resource name (see https://console.cloud.google.com/vertex-ai/model-garden[Vertex AI -> Model Garden]).
| `project`       | `STRING`    | -         | Google cloud project ID.
| `region`        | `STRING`    | -         | Google cloud region (see https://cloud.google.com/vertex-ai/docs/general/locations[Vertex AI -> Locations]).
| `publisher`     | `STRING`    | 'google'  | Model publisher.
| `token`         | `STRING`    | -         | Vertex API access token.
| `chatHistory`   | `LIST<ANY>` | `[]`      | Optional conversation history to provide context to the model. Pass a list of messages as `MAP` values with the keys `role` and `parts` where `role` is either `user` or `model` and the parts is a `LIST` containing a `MAP` with the key `text` and value representing a message. 
| `vendorOptions` | `MAP`       | `{}`      | Optional vendor options that will be passed on as-is in the request to VertexAI (see https://cloud.google.com/vertex-ai/generative-ai/docs/reference/rest/v1/projects.locations.publishers.models/generateContent[Vertex AI -> Method: models.generateContent]).
|===

.Usage example
[source, cypher]
----
WITH
  {
    token: $vertexaiApiAccessKey,
    model: 'gemini-2.5-flash-lite',
    publisher: 'google',
    project: 'my-google-cloud-project',
    region: 'asia-northeast1',
    vendorOptions: {
      systemInstruction: 'Be short.'
    },
    chatHistory: [
      {
        role: "user",
        parts: [
          { text: "My favorite movies are in the Fantasy or Sci-fi genre." }
        ]
      },
      {
        role: "model",
        parts: [
          { text: "Nice! fantasy and sci-fi have great vibes. Want tailored recs?" }
        ]
      }
    ]
  } AS conf
RETURN ai.text.completion('Yes, please recommend a movie to me', 'vertexai', conf) AS result
----


[[providers-bedrock-nova]]
=== Amazon Bedrock Nova Models

This provider supports all models that use the same request parameters and response fields as the Nova text models.

.Amazon Bedrock Nova parameters
[opts=header, cols="1,1,1,3"]
|===
| *Name*            | *Type*      | *Default* | *Description*
| `model`           | `STRING`    | -         | Model ID or its ARN.
| `region`          | `STRING`    | -         | Amazon region (see https://docs.aws.amazon.com/bedrock/latest/userguide/models-regions.html[Amazon Bedrock -> Model Support]).
| `accessKeyId`     | `STRING`    | -         | Amazon access key ID.
| `secretAccessKey` | `STRING`    | -         | Amazon secret access key.
| `chatHistory`     | `LIST<ANY>` | `[]`      | Optional conversation history to provide context to the model. Pass a list of messages as `MAP` values with the keys `role` and `content` where `role` is either `user` or `assistant` and the content is a `LIST` containing a `MAP` with the key `text` and value representing a message.
| `vendorOptions`   | `MAP`       | `{}`      | Optional vendor options that will be passed on as-is in the request to Bedrock (see https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters.html[Amazon Bedrock -> Inference request parameters and response fields]).
|===

.Usage example
[source, cypher]
----
WITH
  {
    accessKeyId: $awsAccessKeyId,
    secretAccessKey: $secretAccessKey,
    model: 'amazon.nova-micro-v1:0',
    region: 'eu-west-2',
    vendorOptions: {
      system: [{ text: 'Be short' }],
      inferenceConfig: { maxTokens: 1024 }
    },
    chatHistory: [
       {
         role: "user",
         content: [
           { text: "My favorite movies are in the Fantasy or Sci-fi genre." }
         ]
       },
       {
         role: "assistant",
         content: [
           { text: "Nice! fantasy and sci-fi have great vibes. Want tailored recs?" }
         ]
       }
    ]
  } AS conf
RETURN ai.text.completion('Yes, please recommend a movie to me', 'bedrock-nova', conf) AS result
----


[[providers-bedrock-titan]]
=== Amazon Bedrock Titan Models

This provider supports all models that use the same request parameters and response fields as the Titan text models.
Configuration and usage is similar to xref:providers-bedrock-nova[Bedrock Nova Models], however, `chatHistory` is not supported.

[NOTE]
Titan models have different `vendorOptions`, see https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters-titan-text.html[Amazon Bedrock -> Titan Text Models].
