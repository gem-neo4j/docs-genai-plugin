[[genai-plugin-deprecations-additions-removals-compatibility]]
= Additions, deprecations, removals, and compatibility
:description: all of the features that have been removed, deprecated, added, or extended in different GenAI releases.
:test-skip: true  // all deprecations would fail.

// Order of subsections:
//  1. Removed features
//  2. Deprecated features
//  3. Restricted features
//  4. Updated features
//  5. New features

This section lists all of the features that have been removed, deprecated, added, or extended in different versions of the GenAI Plugin.
Replacement syntax for deprecated and removed features are also indicated.

[IMPORTANT]
Cypher 25 was introduced in Neo4j 2025.06 and can only be used on Neo4j 2025.06+ databases.
Features removed in Cypher 25 are still available on Neo4j 2025.06+ databases either by prepending a query with `CYPHER 5` or by having Cypher 5 as the default language for the database.
Updates to procedures and functions are only applied to Cypher 25, and won't be available in Cypher 5.
For more information, see link:{neo4j-docs-base-uri}/cypher-manual/25/queries/select-version[Cypher Manual -> Select Cypher version].

[[genai-plugin-deprecations-additions-removals-2025.12]]
== Neo4j 2025.12

=== Updated in Cypher 25

[cols="2", options="header"]
|===
| Feature
| Details

a|
label:functionality[]
label:updated[]

Google VertexAI provider (`apiKey`)
| VertexAI provider configuration now supports authentication via either `apiKey` or `token`.

Applies to the following callables and their provider settings:

* `ai.text.completion` — see xref:generate-text.adoc#providers-vertexai[Generate text -> Google VertexAI].
* `ai.text.embed` and `ai.text.embedBatch` — see xref:embeddings.adoc#providers-google-vertexai[Embeddings -> Google VertexAI].


a|
label:functionality[]
label:updated[]

Base URL can now be updated for OpenAI (default: https://api.openai.com) via the `genai.openai.baseurl` setting in the `genai.conf` file.

|This applies to all `ai.text.*` calls that use OpenAI, including `ai.text.embed`, `ai.text.embedBatch` and `ai.text.completion`.
See xref:reference/config.adoc#_genai_genai_openai_baseurl[Configuration Options -> genai.openai.baseurl].

|===

[[genai-plugin-deprecations-additions-removals-2025.11]]
== Neo4j 2025.11

=== New in Cypher 25

[cols="2", options="header"]
|===
| Feature
| Details

a|
label:functionality[]
label:new[]
[source, cypher, role="noheader"]
----
RETURN ai.text.completion(prompt, provider, configuration)
----
| Introduction of the `ai.text.completion()` function for generating text with external AI providers.
See xref:reference/functions-procedures.adoc#ai-text-completion[ai.text.completion reference] and xref:generate-text.adoc[Generate text].

a|
label:functionality[]
label:new[]
[source, cypher, role="noheader"]
----
RETURN ai.text.embed(resource, provider, configuration)

CALL ai.text.embedBatch(resources, provider, configuration) YIELD index, vector
----
| Introduction of the `ai.text.embed()` function and the `ai.text.embedBatch()` procedure for generating vector embeddings.
See xref:reference/functions-procedures.adoc#ai-text-embed[ai.text.embed], xref:reference/functions-procedures.adoc#ai-text-embed-batch[ai.text.embedBatch], and xref:embeddings.adoc[Embeddings].

|===

=== Deprecated in Cypher 25

[cols="2", options="header"]
|===
| Feature
| Details

a|
label:functionality[]
label:deprecated[]
[source, cypher, role="noheader"]
----
RETURN genai.vector.encode(resource, provider, configuration)

CALL genai.vector.encodeBatch(resources, provider, configuration)
----
| The `genai.vector.encode()` function and the `genai.vector.encodeBatch()` procedure are deprecated, being replaced by `ai.text.embed()` and `ai.text.embedBatch()`.
